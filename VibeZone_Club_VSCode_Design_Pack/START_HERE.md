# VibeZone Club — VS Code implementation package v2

1. Open your **Vibe Zone Gaming App** folder in VS Code (NOT VibeQue DJ request app).
2. Extract this ZIP outside your repository and copy the `docs/design-references/vibezone` directory into the repository's matching location. Merge folders; do not overwrite valuable existing artwork without checking.
3. Open `VIBEZONE_CLUB_CODEX_MASTER_PROMPT_V2.md`, then paste the entire content into Codex with the correct repo as the active workspace. (You can also put the prompt in the repository root, if preferred.)
4. Let Codex inspect, implement, test and update documentation. It must **not** auto-commit, push or deploy.
5. Launch the local preview using the exact command Codex reports; confirm theme selection, moving guests, Vibe Meter, earnings/upgrades, room unlocks and save/reload on desktop and mobile sizes.
6. Do not assume the images themselves are functional game assets; converting concepts into animated models/sprites is an additional production step.

If existing repo already has a `docs/design-references/vibezone/README.md`, review before replacing it.
